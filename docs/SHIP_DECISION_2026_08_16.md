## 依序完成的工作與效益

**1. 修正 FlexHook V1 評測名單**
發現先前的「復現缺口」(53.110 vs 發表值 53.824)是評測名單多算了 8 條格式異常的表達句,不是模型或管線問題。改用官方 150 句名單重新評分後:
→ **native 精確對齊發表值 53.824;加上 GMC 後 54.011 ± 0.025,超過宿主發表分數 +0.19**。論文不再需要任何復現缺口說明。

**2. V2 表格改用正確分類重新統計**
V2 的類別報表先前用改寫句關鍵字分類,108/862 句被分錯。改用原句分類後:
→ **MOVING / STATIC / APPEARANCE / DIRECTION 四類增益全部非負**(+0.048 / +0.294 / +0.125 / +0.021),先前表格上的 MOVING 負值異常消除。

**3. GT 軌跡 oracle 驗證(兩種訓練域各做一次)**
把完美的 ground-truth 軌跡餵進系統,分數與現行配置相同:
→ **消除「特徵品質不足」的疑慮**——現有 motion 特徵已達此架構的實用上限,不需再投入特徵去噪/tracker 強化。

**4. α 選擇加密驗證**
把 α 搜索格從 7 點加密到 16 點、解除邊界截斷,重跑留一序列交叉驗證:
→ **α=0.5 在密格上維持不變**,消除「超參數選擇不穩」的審稿疑慮。

**5. 路面平面 ego 估計鏈(新機制)**
對路面區域(而非全畫面)估計相機運動。三個獨立驗證:
- 2×2 因子實驗:增益確定來自路面鏈本身(MOVING +1.46, t=3.9)
- 跨序列檢查:三個測試序列 MOVING 全正 → **不是單一場景過擬合**
- 訊號層檢查:在最難的序列 0011 上,運動句的分數判別力提升 6 倍(0.022 → 0.135)
→ 找到 MOVING 的新增益來源,且機制、泛化、訊號三層證據齊備。

**6. 句型分流雙權重融合(two-α)**
運動語意句用 α_mot、外觀句用 α_app(15 個關鍵字詞幹的字串比對,無學習成分)。與路面鏈組合,LOSO 誠實選出 (0.7, 0.1):
→ **iKUN pooled 44.847 ± 0.107(+0.191, t=2.5),MOVING 32.606 ± 0.654(+2.56, t=6.7;native 25.53 → 32.61)**
→ 對照組(雙權重用在原 ego 鏈上)完全無效 → 證明增益來自機制組合,不是參數變多。

**7. 消融與速度量測(進行中,今晚完成)**
−ego、−multiscale 各 5 seeds、兩種配置都跑;推理速度 profile 重建。兩個選項的論文材料都會備齊。
