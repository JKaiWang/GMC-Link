# GMC-Link Ship 決定:單一 α vs 路面鏈 + 雙 α

> 目的:忠實呈現兩個候選配置與全部證據,由老師決定論文採用哪一個。
> 所有數字皆為 n=3 seeds、pre-registered 協議、α=0 精確重現 native baseline。

## 一句話問題

我們找到一個新的 ego-motion 估計方式(路面平面 homography 鏈)+ 依句型分流的雙權重融合,
在誠實的 LOSO 交叉驗證下 iKUN pooled HOTA 首次顯著超過現行配置(+0.19, t=2.5;
MOVING +2.56, t=6.7)。**代價:iKUN 的融合超參數從 1 個變 2 個**,部分回退 8/10 決定的
單一 α 簡化。要不要採用?

## 兩個選項

| | 選項 A:單一 α(現行) | 選項 B:road 鏈 + 雙 α |
|---|---|---|
| iKUN pooled | 44.656 ± 0.078 (α=0.5) | **44.847 ± 0.107** (α_mot=0.7, α_app=0.1) |
| iKUN MOVING | 30.045 ± 0.091 | **32.606 ± 0.654**(native 25.53 → +7.08) |
| iKUN STATIC / APPEAR | 44.448 / 46.572 | 44.584 / 46.468(APPEAR −0.10,不顯著) |
| FlexHook V1(官方協議) | **54.011 ± 0.025 (α=7)** — 兩案相同 | 同左 |
| FlexHook V2 | 42.658 ± 0.030 (α=5) — 兩案相同 | 同左 |
| iKUN 超參數 | 1(α) | 2(α_mot, α_app;關鍵字路由,零學習成分) |
| 統計狀態 | LOSO-honest | LOSO-honest,且超過 pre-registered 升級門檻(44.812) |

兩案差異只在 iKUN;FlexHook 兩個 split 完全不動。

## 選項 B 是什麼

1. **Ego 估計換成路面平面鏈**:對路面區域(而非全畫面)估計逐幀 homography 再連乘;
   殘差速度在此鏈下計算。訓練與推理端一致。
2. **融合權重依句型分兩檔**:`s_final = s_host + α(句型)·s_gmc`。
   句子含運動關鍵字(moving/turning/parked 等)→ α_mot=0.7;
   純外觀句(black cars 等)→ α_app=0.1。分流是 15 個詞幹的字串比對,無學習模型;
   α_mot=α_app 時完全退化回選項 A 公式。

## 支持選項 B 的證據鏈(ledger 編號可查 RESEARCH_NOTES §10)

- **A23/A25(歸因)**:2×2 因子實驗證明增益來自路面鏈本身,不是接地點
  (road-only MOVING +1.46, t=3.9;接地點 ≈ 0)。
- **A28(非場景過擬合)**:增益跨序列分佈——α=1.0 時三個測試序列 MOVING 全正
  (+1.7 / +2.5 / +1.8);最大增益在最難的 0011。
- **A29(機制)**:路面鏈把 0011 上「運動句 vs 物件」的分數判別力修復 6 倍
  (分離度 0.022 → 0.135)——正是 sim 鏈訊號失效的地方。
- **A32(LOSO 勝利)**:雙 α 在 road caches 上 LOSO 選出 (0.7, 0.1),
  full-test 44.847 ± 0.107,超過升級門檻;**對照組:雙 α 用在現行 sim 鏈上完全無效
  (+0.016, t=0.34)**——證明不是「多參數揀便宜」,是機制組合。
- 完整性:對角線 α_mot=α_app 逐位重現單 α;α=0 逐位重現 native 44.224;
  全部實驗 pre-registration 先於數據進 git。

## 反對選項 B 的理由(誠實列出)

1. **違背簡化方向**:8/10 老師指示收斂到單一 α;選項 B 讓 iKUN 回到 2 個超參數。
   (辯護:路由是固定字串規則非學習;FH 端維持單 α;審稿可驗證。)
2. **單 α 下 road 鏈選不到增益**(A27):road 的 per-sequence 最適 α 分裂
   ({0.2, >2.0}),單 α LOSO 折衷後 MOVING 反而輸 −0.62。雙 α 是必要成分,
   兩者綁定採用。
3. **機制的物理解釋還是假說**:「繞過深度視差」有 A29 的訊號證據(0011 序列)支持,
   但未在幾何層完全證明;論文措辭會寫「歸因已證、機制假說」。
4. 測試集只有 3 條序列——所有結論的統計基礎上限。
